# MTC ERP — Python dependencies
#
# Every entry below is either imported by the code or invoked as a command, and
# each is annotated with which. Anything that stops being either should be
# deleted rather than left "just in case" -- an unused pin is a version to keep
# patched, a licence to audit and a wheel to build, for nothing.
#
# THE environment for this project is `venv2`, at the repo root. `venv` was
# retired (renamed to `venv.obsolete`) after it caused a real outage: the
# server ran from venv2 while weasyprint had been installed into venv, so the
# Download PDF buttons returned 503 and reported the renderer as unavailable.
#
# A missing package here surfaces as a feature that silently degrades rather
# than a crash, which is exactly why it went unnoticed -- so install into the
# environment that actually runs the app:
#
#     venv2\Scripts\python -m pip install -r requirements.txt

# ── Core framework ───────────────────────────────────────────────────
Flask==3.0.0
# 3.0.6, not 3.0.1: PYSEC-2026-3417, a multipart/form-data parse that can
# bypass Request.max_form_memory_size and exhaust memory. Patch-level bump
# inside 3.0.x, so Flask 3.0.0's `Werkzeug>=3.0.0` is satisfied unchanged.

# deploys on Linux. The debugger-PIN one needs debug mode, which production
# refuses to start with.

# ── Progressive Web App: document export ─────────────────────────────
# The PWA prints and exports every document -- purchase orders, challans,
# ledgers, production sheets -- through the browser's own print engine
# (static/erp/print.js). That needs nothing installed.
#
# WeasyPrint covers the one thing a print dialog cannot do: hand back a FILE.
# It backs the "Download PDF" buttons, and bulk export as N separately-named
# PDFs, by rendering the SAME print HTML the browser renders
# (app/erp/services/pdf_render_service.py) -- one definition of every document,
# not two.
#
# It needs system libraries, NOT just pip:
#   Debian/Ubuntu/Docker  apt install libpango-1.0-0 libpangoft2-1.0-0 \
#                                     libharfbuzz-subset0
#   Windows (dev)         winget install MSYS2.MSYS2
#                         pacman -S mingw-w64-x86_64-pango
#                         (the service finds C:/msys64/mingw64/bin by itself;
#                          no PATH editing needed)
#
# Without them the endpoint returns 503, the Download buttons say so, and Print
# still produces a searchable PDF. Verify with:
#   python -m app.erp.services.pdf_render_service
weasyprint==69.0
